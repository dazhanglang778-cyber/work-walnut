# Security

Do not disclose exploitable security or privacy details in a public Issue. Contact maintainer `dazhanglang` through an available private channel, or use GitHub Private Vulnerability Reporting once enabled. Include the affected version, reproduction conditions, potential impact, and suggested mitigation. Use the public Bug template for ordinary functional problems.

---

# 安全说明

如果你发现可能影响用户电脑或隐私的安全问题，请不要在公开 Issue 中披露利用细节。请先通过 GitHub 仓库作者主页可用的私密联系方式联系维护者 `dazhanglang`；待仓库启用 GitHub Private Vulnerability Reporting 后，优先使用该入口。

请提供受影响版本、复现条件、潜在影响和建议修复方式。普通功能缺陷请使用 Bug 报告模板。
