# 工作坚果使用指南

## 1. 启动

### Windows 便携版

1. 从 GitHub Releases 下载 `工作坚果-Windows-x64-v1.0.0.zip`。
2. 将 ZIP 完整解压到普通文件夹。
3. 双击 `启动工作坚果.exe`。

请保留 EXE 旁边的 `_internal` 文件夹。只把 EXE 单独发送或复制到别处，会导致程序无法启动。

### macOS 测试版

1. Apple Silicon Mac 下载 `工作坚果-macOS-arm64-v1.0.0.zip`；Intel Mac 下载 `工作坚果-macOS-x64-v1.0.0.zip`。
2. 解压后打开 `工作坚果.app`。
3. 当前测试版没有 Apple Developer 签名和公证。请保留 Gatekeeper，只在确认下载来源与 SHA-256 后，通过系统“隐私与安全性”单独允许工作坚果。

Mac 触控板可用双指点按执行右键操作，也支持 `Control` + 单击。菜单栏与 Dock 的预留边距可通过 `mac_safe_margins` 调整。

### 源码版

1. 安装 Python 3.10 或更高版本，并包含 Tkinter。
2. 在仓库根目录执行 `python -m pip install -r requirements.txt`。
3. 双击 `启动源码版.bat`，或执行 `python app/wallnut_pet.py`。

## 2. 鼠标操作

| 操作 | 行为 |
|---|---|
| 左键单击坚果 | 播放一次轻微弹跳 |
| 按住左键拖动 | 移动坚果；可贴到屏幕上、左、右边缘和任务栏上沿 |
| 左键双击坚果 | 向屏幕内侧滚动两圈 |
| 右键单击坚果 | 打开菜单 |
| 右键双击坚果 | 沿随机对角线弹射，在可用桌面边缘反弹并逐渐减速 |
| 单击对话气泡 | 关闭气泡 |
| 单击周期末绿字 | 关闭绿字、恢复正常并从 0 分钟重新计时 |

如果双击被识别成拖动，请尽量让两次点击落在坚果中间，点击期间不要移动鼠标。

## 3. 右键菜单

- `切换到：正常/轻伤/受伤/海盗/重伤/疯狂/红温`：手动查看指定状态，并把计时同步到该状态的起始时间。
- `恢复精神`：立即回到正常状态，并把本轮计时归零。
- `暂停随机晃动` / `继续随机晃动`：控制待机时偶尔出现的轻微晃动。
- `退出桌宠`：完整关闭程序。

右键双击会触发弹射。程序会短暂等待第二次右键，因此右键菜单可能在一次点击后稍晚出现，这是为了区分单击和双击。

## 4. 状态与时间

| 起始时间 | 状态 |
|---:|---|
| 0 分钟 | 正常 |
| 45 分钟 | 轻伤 |
| 90 分钟 | 受伤 |
| 135 分钟 | 海盗 |
| 180 分钟 | 重伤 |
| 225 分钟 | 疯狂 |
| 270 分钟 | 红温 |
| 315 分钟 | 显示随机绿字，等待用户单击后重置 |

这里的“工作时间”指桌宠运行且电脑清醒的时间：

- 程序不会监控键盘、鼠标或具体应用。
- Windows 休眠或长时间暂停不会被一次性计入大量时间。
- 每次关闭后重新启动，计时从正常状态重新开始。
- 程序跨自然日持续运行时，也会回到正常状态重新开始。

## 5. 气泡提醒

状态变化时会随机出现一句提醒，其中包括喝水、走动、休息、暖心安慰和轻微毒舌文案。气泡不会自动阻止你工作，单击即可关闭。

动态工时文案会根据当前累计时间生成，例如“你已经工作45分钟了。”；小时和分钟混合时会自动换行，避免拆散分钟数字。

## 6. 配置文件

配置位于 `app/config.json`：

| 字段 | 含义 |
|---|---|
| `window_size` | 透明悬浮窗口大小，通常无需修改 |
| `pet_size` | 普通坚果显示尺寸 |
| `drag_threshold_pixels` | 鼠标移动超过多少像素后判定为拖动 |
| `wobble_interval_seconds` | 两次随机晃动之间的最短、最长秒数 |
| `roll_distance` | 双击滚动距离 |
| `launch_speed` | 弹射初速度范围 |
| `launch_drag` | 弹射阻力，越小减速越快 |
| `launch_restitution` | 碰壁后的反弹系数 |
| `launch_max_seconds` | 单次弹射最长时间 |
| `launch_stop_speed` | 低于此速度后允许停止 |
| `fatigue_minutes` | 七个状态的起始分钟数 |
| `green_message_minutes` | 周期末绿字出现时间 |
| `auto_fatigue` | 是否自动按照时间切换状态 |
| `mac_safe_margins` | macOS 左、上、右、下的安全边距，用于避开菜单栏与 Dock |

修改 JSON 时必须保留英文双引号、逗号和方括号。修改前建议备份原文件。

## 7. 退出与卸载

先右键坚果并选择 `退出桌宠`。便携版没有安装服务和卸载程序，退出后删除整个文件夹即可。工作坚果不会主动删除或修改你的个人文件。
