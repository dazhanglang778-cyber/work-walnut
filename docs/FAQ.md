# 常见问题

## 双击 EXE 没反应怎么办？

请先确认你已经完整解压 ZIP，而不是在压缩软件预览窗口中直接运行，并确认 EXE 旁边仍有 `_internal` 文件夹。便携版必须以完整文件夹形式运行。

如果仍然失败，请在 Issue 中提供 Windows 版本、工作坚果版本、解压路径和错误截图；截图前请遮住个人信息。

## 为什么源码版提示 `No module named 'tkinter'`？

你的 Python 安装不包含 Tcl/Tk。最简单的处理方式是改用 Release 便携版；它会把运行所需组件一起打包。源码开发者则需要重新安装带 Tcl/Tk 的官方 Python。

## 为什么源码版提示缺少 `PIL`？

在仓库根目录运行：

`python -m pip install -r requirements.txt`

## Windows SmartScreen 提示“已保护你的电脑”怎么办？

个人开源项目的未签名 EXE 可能因为下载量和信誉不足而触发提示，这不等于一定存在恶意行为。请从本仓库的正式 Release 下载，并核对发布页提供的 SHA-256。

不要关闭杀毒软件或系统安全功能。如果文件哈希不一致、下载来源不可信，或安全软件给出明确恶意判定，请停止运行并报告问题。

## 为什么没有 MSI 安装包？

项目刻意采用便携版：解压即用、删除即卸载，也避免为一个小桌宠引入复杂安装流程。

## 状态时间是实际工时吗？

不是。程序只统计桌宠运行且电脑清醒的时间，不读取键盘鼠标活动，也不知道你是否真的在工作。

## 关闭程序以后时间还会保留吗？

不会。当前版本不保存跨进程计时；每次重新启动都会从正常状态开始。跨自然日持续运行也会重置。

## 怎么立刻回到正常状态？

右键坚果，选择 `恢复精神`。周期末出现绿字时，直接单击绿字也会恢复正常并重新计时。

## 为什么右键菜单稍微慢一点出现？

程序会等待约四分之一秒，确认这次操作不是右键双击弹射，然后才显示菜单。

## 为什么滚动或弹射时坚果会旋转？

滚动固定转两圈；弹射旋转速度跟随移动速度逐渐降低。角色在靠近屏幕边缘时会锁定运动中心，减少因为非圆形轮廓产生的颠簸。

## 支持 macOS 或 Linux 吗？

提供 Apple Silicon 和 Intel 两种 macOS 测试版。Mac 的透明窗口、菜单栏/Dock 边界和触控板操作需要真实设备继续验证；不同 Dock 位置可通过 `mac_safe_margins` 调整预留边距。

Linux 暂未列入 v1.0.0，因为 X11、Wayland 和不同桌面环境的透明悬浮窗口行为差异较大。

## macOS 为什么提示无法验证开发者？

当前测试版没有 Apple Developer 签名和公证。请不要全局关闭 Gatekeeper。先确认 ZIP 来自本仓库正式 Release 并核对 SHA-256，再通过系统“隐私与安全性”单独允许 `工作坚果.app`。如果仍无法启动，请提交 Mac 芯片类型、macOS 版本和提示截图。

## 它会开机启动吗？

当前版本不会自行添加开机启动项，也不会安装后台服务。

## 如何卸载？

右键退出桌宠，然后删除解压出来的整个文件夹即可。

## 它会上传数据吗？

不会。当前代码没有账号、联网请求、遥测、广告或分析功能。详见 [PRIVACY.md](PRIVACY.md)。

## 可以修改和发布自己的版本吗？

代码可以按照 GPL-3.0-only 修改和再发布，但视觉素材不随 GPL 授权。制作修改版时，你需要单独确认素材权利，最稳妥的方式是替换为原创或已获许可的素材。详见 [ASSET_NOTICE.md](../ASSET_NOTICE.md)。

## 我是素材权利人，如何联系移除？

请使用仓库的“版权或素材问题”Issue 模板，说明涉及文件、权利或原始出处，以及希望采取的署名、替换或移除措施。维护者会善意核查并处理。
